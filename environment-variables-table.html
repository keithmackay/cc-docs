Environment Variables Reference Guide

🔐 Authentication and API 4 variables
Configure authentication methods for Claude Code. These variables control API keys, authorization tokens, and custom headers used when communicating with Anthropic's services or AWS Bedrock.
Variable Description Default Example
ANTHROPIC_API_KEY API key sent as X-Api-Key header, typically for the Claude SDK (for interactive usage, run /login) - sk-ant-api03-...
ANTHROPIC_AUTH_TOKEN Custom value for the Authorization header (the value you set here will be prefixed with Bearer ) - my-custom-token
ANTHROPIC_CUSTOM_HEADERS Custom headers you want to add to the request (in Name: Value format) - X-Custom-Header: value
AWS_BEARER_TOKEN_BEDROCK Bedrock API key for authentication - bedrock-key-123...
🤖 Model Configuration 7 variables
Control which Claude models are used for different tasks. Configure model aliases (sonnet, opus, haiku) and specify models for subagents. These settings determine the AI model behavior and capabilities for your Claude Code instance.
Variable Description Default Example
ANTHROPIC_MODEL Name of the model setting to use (see Model Configuration) - sonnet
ANTHROPIC_DEFAULT_HAIKU_MODEL See Model configuration - claude-3-5-haiku-20241022
ANTHROPIC_DEFAULT_OPUS_MODEL See Model configuration - claude-opus-4-20250514
ANTHROPIC_DEFAULT_SONNET_MODEL See Model configuration - claude-sonnet-4-20250514
ANTHROPIC_SMALL_FAST_MODEL DEPRECATED [DEPRECATED] Name of Haiku-class model for background tasks - Use ANTHROPIC_DEFAULT_HAIKU_MODEL
ANTHROPIC_SMALL_FAST_MODEL_AWS_REGION Override AWS region for the Haiku-class model when using Bedrock - us-west-2
CLAUDE_CODE_SUBAGENT_MODEL See Model configuration - claude-3-5-sonnet-20241022
⚙️ Bash and Command Execution 4 variables
Manage how Claude Code executes bash commands. Set timeouts for long-running commands, control output length limits, and configure working directory behavior to optimize command execution in your workflow.
Variable Description Default Example
BASH_DEFAULT_TIMEOUT_MS Default timeout for long-running bash commands 120000 300000 (5 min)
BASH_MAX_TIMEOUT_MS Maximum timeout the model can set for bash commands 600000 900000 (15 min)
BASH_MAX_OUTPUT_LENGTH Maximum number of characters in bash outputs before they are middle-truncated - 50000
CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR Return to the original working directory after each Bash command - 1
🌐 Cloud Infrastructure (Bedrock/Vertex) 9 variables

Variable Description Default Example
CLAUDE_CODE_USE_BEDROCK Use Bedrock - 1
CLAUDE_CODE_USE_VERTEX Use Vertex - 1

VERTEX_REGION_CLAUDE_3_5_HAIKU Override region for Claude 3.5 Haiku when using Vertex AI - us-central1
VERTEX_REGION_CLAUDE_3_7_SONNET Override region for Claude 3.7 Sonnet when using Vertex AI - us-east5
VERTEX_REGION_CLAUDE_4_0_OPUS Override region for Claude 4.0 Opus when using Vertex AI - us-central1
VERTEX_REGION_CLAUDE_4_0_SONNET Override region for Claude 4.0 Sonnet when using Vertex AI - us-east5
VERTEX_REGION_CLAUDE_4_1_OPUS Override region for Claude 4.1 Opus when using Vertex AI - us-central1
🔌 MCP (Model Context Protocol) 3 variables
Configure Model Context Protocol (MCP) server behavior. Control timeouts for server startup and tool execution, and set limits on output token size to manage MCP server performance and resource usage.
Variable Description Default Example
MCP_TIMEOUT Timeout in milliseconds for MCP server startup - 30000
MCP_TOOL_TIMEOUT Timeout in milliseconds for MCP tool execution - 60000
MAX_MCP_OUTPUT_TOKENS Maximum number of tokens allowed in MCP tool responses. Claude Code displays a warning when output exceeds 10,000 tokens (default: 25000) 25000 50000
🔄 Proxy and Network 3 variables
Configure network proxy settings for corporate environments. Set HTTP/HTTPS proxy servers and define exceptions for domains that should bypass the proxy, enabling Claude Code to work behind corporate firewalls.
Variable Description Default Example
HTTP_PROXY HTTP proxy server for network connections - http://proxy.company.com:8080
HTTPS_PROXY HTTPS proxy server for network connections - https://proxy.company.com:8443
NO_PROXY Domains/IPs to bypass proxy - localhost,127.0.0.1,.internal.com
🛡️ Security and Certificates 3 variables
Set up mutual TLS (mTLS) authentication for enhanced security. Configure client certificates, private keys, and passphrases required for secure communication in enterprise environments with strict security requirements.
Variable Description Default Example
CLAUDE_CODE_CLIENT_CERT Path to client certificate file for mTLS authentication - /path/to/client-cert.pem
CLAUDE_CODE_CLIENT_KEY Path to client private key file for mTLS authentication - /path/to/client-key.pem
CLAUDE_CODE_CLIENT_KEY_PASSPHRASE Passphrase for encrypted client key (optional) - my-secure-passphrase
📊 Telemetry and Debugging 5 variables
Control data collection and reporting features. Disable telemetry, error reporting, automatic updates, and debug commands. These settings help maintain privacy and control over what data is shared with Anthropic's services.
Variable Description Default Example
DISABLE_TELEMETRY Set to 1 to opt out of Statsig telemetry (note that Statsig events do not include user data like code, file paths, or bash commands) - 1
DISABLE_ERROR_REPORTING Set to 1 to opt out of Sentry error reporting - 1
DISABLE_BUG_COMMAND Set to 1 to disable the /bug command - 1
DISABLE_AUTOUPDATER Set to 1 to disable automatic updates. This takes precedence over the autoUpdates configuration setting. - 1
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC Equivalent of setting DISABLE_AUTOUPDATER, DISABLE_BUG_COMMAND, DISABLE_ERROR_REPORTING, and DISABLE_TELEMETRY - 1
💡 UX and Behavior 4 variables

Variable Description Default Example

DISABLE_COST_WARNINGS Set to 1 to disable cost warning messages - 1
DISABLE_NON_ESSENTIAL_MODEL_CALLS Set to 1 to disable model calls for non-critical paths like flavor text - 1

⚡ Optimization and Performance 8 variables
Fine-tune performance and resource usage. Configure output token limits, enable extended thinking, control prompt caching per model, and optimize tools like ripgrep. These settings help balance performance, cost, and quality.
Variable Description Default Example
CLAUDE_CODE_MAX_OUTPUT_TOKENS Set the maximum number of output tokens for most requests - 8192
MAX_THINKING_TOKENS Enable extended thinking and set the token budget for the thinking process. Extended thinking improves performance on complex reasoning and coding tasks but impacts prompt caching efficiency. Disabled by default. Disabled 10000
DISABLE_PROMPT_CACHING Set to 1 to disable prompt caching for all models (takes precedence over per-model settings) - 1
DISABLE_PROMPT_CACHING_HAIKU Set to 1 to disable prompt caching for Haiku models - 1
DISABLE_PROMPT_CACHING_OPUS Set to 1 to disable prompt caching for Opus models - 1
DISABLE_PROMPT_CACHING_SONNET Set to 1 to disable prompt caching for Sonnet models - 1
SLASH_COMMAND_TOOL_CHAR_BUDGET Maximum number of characters for slash command metadata shown to SlashCommand tool (default: 15000) 15000 20000
USE_BUILTIN_RIPGREP Set to 0 to use system-installed rg intead of rg included with Claude Code - 0
